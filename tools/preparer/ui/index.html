    Riparr

    Preparer

    Riparr is a disc ripper you feed and walk away from: put a Blu-ray or DVD in the tray and the file lands on your library share, named, checked and ready to play.

    This app builds one. It writes the software onto an SD card, hands you the card, then finds the box on your network and installs everything on it for you. You will not need a terminal at any point.

    Choose your SD card

    Your startup disk can never appear here. Anything that looks like an external drive rather than a card is kept out of the list below and shown separately, so a backup disk cannot be picked by accident.

    Show other removable disks

    These did not identify themselves as cards. One of them may be an external drive with your files on it. Writing to it erases it.

    What size card should I use?

    Under adaptive streaming, the upload follows the rip rather than waiting for it, so every card size rips every disc — 4K included. Size does not decide what fits. It decides how long the drive stays busy, and therefore whether you can load a stack of discs and leave.

    Buy for how you feed it, not for what you rip. One disc at a time whenever you think of it → 32 GB is genuinely fine. Six discs in an evening → 128 or 256 GB. At Blu-ray sizes buy high-endurance (SanDisk Max Endurance, Samsung Pro Endurance) rather than A2 — this is a write-amplification machine — and not SD Express, which falls back to legacy speed on this board and costs three to four times as much.

    Join a Wi-Fi network

    The box has dual-band Wi-Fi, so 5 GHz is available and worth taking — uploading is the slowest part of a rip. Anything the board's radio can't reach (6 GHz) is listed but greyed out.

    Get the password right here. Nothing downstream can check it: the card writes, the box boots, and it simply never appears on your network. If this Mac already knows the network, take the password from it.

    Band and signal are hidden macOS only reveals nearby network names, bands and signal strength to apps allowed to use Location Services. Without it this list is the networks this Mac remembers, and the band is unknown.

    Networks this Mac remembers (0) — not necessarily in range

    Converted to a PBKDF2 key before it is written. The passphrase itself never touches the card.

    Name your Riparr

    This is the name you'll type into a browser to reach it.

    Reachable at http://riparr.local:9797

    9797 is Riparr's own port, chosen to sit alongside Radarr on 7878 and Sonarr on 8989. Change it only if something already uses it.

    System account

    Used only for SSH and the console. This is not the web login — you'll create that on first run.

    Userriparr
    Password —

    You don't need to write this down. It is saved in user_password.txt in your build folder, and this app reads it back every time — so re-writing a card keeps the same login rather than locking you out of a box you already set up. You will only ever need it if you connect a keyboard and screen to the board, or SSH in by password instead of by key.

    Check before writing

    Everything currently on the card will be erased.
